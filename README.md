# 🚀 Employee Management System

A modern **Employee Management System Web Application** built using **HTML, CSS, and JavaScript** to manage employee data, attendance, company profiles, and internal communication.

---

# 🌐 Live Demo

🔗 https://employee-management-system-liard-omega.vercel.app

---

# 📌 Project Overview

This project simulates a **corporate employee management dashboard** where administrators can manage employee information, track attendance, handle leave requests, and maintain internal communication.

The system demonstrates how a modern web dashboard works using only front-end technologies.

---

# ✨ Features

### 📊 Dashboard

Provides a centralized overview of employee activities.

### 👨‍💼 Employee Management

* View employees
* Add new employees
* Manage employee profiles

### 📅 Attendance Tracking

Monitor employee attendance records.

### 📝 Leave Management

Submit and manage leave requests.

### 💬 Messaging

Internal communication system between employees.

### 🏢 Company Profile

Manage company information and details.

### ⚙ Settings

Application configuration and preferences.

### 🔐 Authentication

* Login
* Registration

# ⚙ Installation

Clone the repository

```
git clone https://github.com/lucifer13598/employee-management-system.git
```

Open the project folder

```
cd employee-management-system
```

Run the project by opening

```
index.html
```

in your browser.
